Field Outputs

Hold a strip to override its output. Momentary returns on release; Latch holds your requested value.

Sample Spread

Fixed sample points in a moving 3D field. Manual preserves per-lane coordinates.

Spread is radius for Ball/Sphere and RMS radius for fully random Gaussian. Randomness blends regular placement into a seeded random layout. Points remain fixed over time. Placement seed does not change the noise field. Manual mode ignores these placement controls.

Connecting…

Green: effective output · grey: underlying field · L: latched. Release buttons return to the field. Values are normalized before each lane’s range mapping. “Unmapped” lanes have no destination yet. Arrow keys fine-adjust while held; Shift gives smaller steps. No output gestures are recorded.
